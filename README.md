# Pencil Canvas

An unlimited vector drawing canvas for Obsidian, with Apple Pencil support and Procreate / Krita brush import. Drawings are saved as `.pencil` files in your vault.

## Install with BRAT (iPad, iPhone, desktop)

1. Install **BRAT** from Settings → Community plugins → Browse, and enable it.
2. Open BRAT's settings and choose **Add beta plugin**.
3. Paste `https://github.com/chiharul/obsidian-pencil-canvas` and confirm.
4. Enable **Pencil Canvas** under Settings → Community plugins.

## Manual install

Download `main.js`, `manifest.json` and `styles.css` from the latest release and put them in `<vault>/.obsidian/plugins/applepencilsync/`.

## Building

```bash
npm install
npm run build
```
